# PROJECT.md — Mossine Digital

## Vision

**Mossine Digital** est une agence de communication et marketing digital 360.
Le site vitrine doit être la **référence absolue** en matière de design UI premium,
expérience utilisateur, sécurité, SEO et scalabilité sur le marché francophone.

## Objectif principal

Convertir les visiteurs en clients via un site qui inspire confiance, démontre
l'expertise et reflète un positionnement ultra-premium.

## Pages cibles (MVP)

| Page          | Description                                              |
|---------------|----------------------------------------------------------|
| `/`           | Accueil — Hero cinématique, services, témoignages, CTA  |
| `/services`   | Détail des offres (branding, web, social, SEO, ads)     |
| `/portfolio`  | Réalisations clients avec filtres et lightbox           |
| `/agence`     | Histoire, équipe, valeurs, culture                      |
| `/blog`       | Articles SEO via Sanity CMS                             |
| `/contact`    | Formulaire sécurisé + Google Maps                       |

## Tonalité

- Professionnel, moderne, ambitieux
- Warm mais expert — jamais froid ou corporate
- Copywriting en français, sans fautes

## KPIs de succès

- LCP < 2.5s, CLS < 0.1, FID < 100ms
- Lighthouse score ≥ 95 sur toutes les métriques
- Accessibilité WCAG 2.2 AA sur chaque page
- 0 vulnérabilité critique (OWASP Top 10)

## Contraintes

- Budget outils : zéro outil payant sans validation client
- Hébergement : Hostinger Cloud (pas Vercel)
- Langue principale : français
- RGPD : analytics Umami (self-hosted), pas de Google Analytics
